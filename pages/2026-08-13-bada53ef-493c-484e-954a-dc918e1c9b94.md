# DeepSeek、Grok、Qwen同日亮剑，AI Agent战国启幕

## 模型竞技场：旗舰模型同日交锋

### [DeepSeek V4 Pro 正式版上线，API 将引入峰谷定价](https://www.qbitai.com/2026/08/471642.html)

DeepSeek 在 8 月 13 日晚发布 **DeepSeek-V4-Pro-0813** 正式版，已同步上线 App、网页端与 API。官方称新版本重点强化了 **Agent 能力与生产环境表现**，在 Terminal Bench、CyberGym、AutomationBench 等偏推理、终端操作、安全任务的测试中超过 Anthropic Opus 4.8，整体逼近 Fable 5。

API 层面有两个关键更新：
- 原生支持 **OpenAI Responses API** 格式，并针对 Codex 做了适配；
- 思考模式新增 low / high / max 三档，用户可按任务复杂度调节推理深度。

定价维持输入 3 元 / 百万 tokens、输出 6 元 / 百万 tokens 的低价路线，但 8 月 17 日起将实行**峰谷定价**，闲时价格为高峰时段的一半。官方同时预告 DeepSeek V4 系列将整体调价。

**深度解读 & 洞察：**
- 这是 DeepSeek 从「参数内卷」转向「工程化落地」的信号：Agent 兼容性、Codex 一键接入、推理档位和峰谷计费，都是围绕真实部署场景打磨。
- 峰谷定价本质上把算力成本波动转嫁给用户调度能力，对批量任务的团队是利好，对实时性要求高的应用则增加复杂度。
- V4 Pro 的 CoT（思维链）被反馈变得极为简略，这是为了降低 token 消耗和推理成本，但代价是创意写作、长文本连贯性可能变弱。说明 DeepSeek 正在把能力优先级明确押在 Coding 与 Agent 任务上。

**影响：**
- 对 AI 应用开发者偏利多：同等 Agent 能力下调用成本显著低于闭源竞品，利好中小团队与海外用户迁移。
- 对 Anthropic/OpenAI 股价预期偏空：价格战持续压缩高端模型毛利，企业客户会更敏感地比价。
- 投资风险：DeepSeek 若因算力紧张频繁调价或限流，可能拖累依赖其 API 的商业化应用稳定性。

### [SpaceXAI 发布 Grok 4.6，性能追平 GPT-5.6 Sol 但便宜超六成](https://www.oschina.net/news/501917/grok-4-6)

xAI/SpaceXAI 在 8 月 12 日晚发布 **Grok 4.6**。在 Artificial Analysis Intelligence Index 上获得 **61 分**，与 OpenAI GPT-5.6 Sol（Max）持平，仅次于 Claude Opus 5（63 分）和 Fable 5（62 分）。这意味着 Grok 系列首次进入全球顶尖模型第一梯队。

Agent 能力进步更明显：
- GDPval-AA v2：1753 Elo，仅次于 Claude Opus 5；
- DeepSWE v1.1：从 54% 提升至 65.9%；
- Terminal-Bench v3.0：从 15.7% 提升至 26%；
- AA-Briefcase 长周期知识工作：平均仅 53 个回合、约 5 亿输入 token，而 Claude Opus 5 需约 103 个回合、约 20 亿 token。

定价维持输入 2 美元 / 百万 token、输出 6 美元 / 百万 token，比 Claude Opus 5（5/25 美元）和 GPT-5.6 Sol（5/30 美元）低 60% 以上。Grok 4.6 已通过 Cursor、Grok Build、API 及 OpenRouter、Vercel、Cloudflare 等渠道上线。

**深度解读 & 洞察：**
- Grok 4.6 的核心竞争力不是单项冠军，而是「顶级性能 + 显著低价」的组合。这延续了马斯克一贯的低价颠覆打法。
- 训练方式上，Grok 4.6 用 Grok 4.5 自生成高质量 SFT 轨迹和推理数据，再叠加强化学习，形成了「模型自己生产饲料」的闭环。这种数据飞轮一旦跑通，迭代速度会更快。
- 与 Cursor 的协同是另一层看点：Grok 4.5 是 xAI 与 Cursor 首次联合训练，Cursor 海量真实开发者交互数据成为关键燃料。SpaceX 收购 Cursor 母公司 Anysphere 后，模型与工具链的整合才刚刚开始。

**影响：**
- 对 AI Agent 和编程工具市场偏利多：更低成本的旗舰模型会加速企业级 Agent 落地。
- 对 OpenAI/Anthropic 偏空：Grok 4.6 以不到对手四成的价格提供可比的 Agent 能力，企业采购时议价空间增大。
- 投资者启示：关注模型成本曲线下降带来的「应用层受益」逻辑，特别是高频调用 Agent 的 SaaS 公司。

### [阿里开源 Qwen3.8-2.4T-A95B，Max 级旗舰模型首次进入社区](https://www.oschina.net/news/501918)

阿里通义千问团队发布 **Qwen3.8-2.4T-A95B** 开源模型，这是 Qwen-Max 级别模型首次面向社区开放权重。模型总参数 **2.4 万亿**，单次前向传播仅激活 **950 亿** 参数，采用混合专家（MoE）架构。

主要规格：
- 原生上下文 26.2 万 token，可扩展至 101 万 token；
- 每层 512 个专家，每次激活 10 个路由专家 + 1 个共享专家；
- 线性注意力（Gated DeltaNet）与标准注意力（Gated Attention）混合设计；
- 仅支持 thinking 模式，可通过 reasoning_effort 调节推理深度。

性能方面，Qwen3.8-Max 云端 API 版本在 Terminal Bench 2.1、PaperBench、GPQA Diamond 等基准上处于开源模型领先位置，支持连续 16 天自主编程、论文复现、365 天电商经营模拟等长程任务。模型已在 Hugging Face、魔搭社区上架，并提供 8 种量化版本。

**深度解读 & 洞察：**
- 开源阵营正在从「追赶闭源」变成「局部反超」。Qwen3.8-2.4T-A95B 的规格已经接近甚至超过部分闭源旗舰，这对全球开源生态是重大弹药补充。
- 只开放 thinking 模式是一个策略性取舍：既让社区能研究和二次训练，又保留非 thinking、视觉、工具调用等能力在云端 API 收费。这是「开源引流 + 云端变现」的典型打法。
- 模型大到 2.4T 参数，即便激活稀疏，部署成本依然很高。量化版本和 SGLang/vLLM/TokenSpeed 等推理引擎支持，说明阿里希望降低研究和政企私有化门槛。

### [韩国 Upstage 发布 Solar Pro 4，瞄准复杂 Agent 任务](https://www.ithome.com/0/989/171.htm)

韩国 AI 实验室 Upstage 发布 **Solar Pro 4** 商用大模型，定位复杂 AI Agent 任务。上下文窗口 **512K**，最高输出 **128K token**。定价为输入 0.3 美元 / 百万 tokens、缓存读取 0.06 美元、输出 1.2 美元 / 百万 tokens。

官方测试成绩：Terminal-Bench v2.1 得 57 分，τ³-Banking 23 分，AA-LCR 71 分。在 Agent Arena 榜单中排名第 44，与 MiniMax M2.7、Nemotron 3 Ultra 同级，是首个登上该榜单的韩国实验室模型。

**深度解读 & 洞察：**
- Solar Pro 4 的亮点不在 SOTA，而在于「长上下文 + 低价 + 真实工作流优化」。它代表了一股新趋势：二线模型厂商不再硬刚综合榜，而是选择 Agent、长文档、金融等垂直场景做性价比。
- 韩国模型进入全球 Agent 评测榜单，说明非中美市场的模型竞争力正在分化。未来可能出现「美国闭源 + 中国开源 + 区域性价比模型」的三层结构。

## 智能体基础设施：从模型到操作系统的跃迁

### [DeepSeek Harness 公测并开源，用「插件一切」挑战 AI 编程形态](https://www.ithome.com/0/989/446.htm)

DeepSeek 在发布 V4 Pro 的同时推出 **DeepSeek Harness（DSH）** 开发者预览版，并以 MIT 协议开源。DSH 是一个把模型转化为智能体的运行时框架，官方给出公式：**Model + Harness = Agent**。

产品特性：
- 提供 `dsh` 命令行工具，支持 Web、Headless 等运行模式；
- 采用 **Cordis 插件系统**，模型、工具、技能、会话、沙箱、存储、循环、调度、UI 等全部组件均可插拔替换；
- 内置 Trajectory 视图，可回放 Agent 原始事件级记录与 token 消耗；
- 同步开放 NPM 插件生态。

DSH 定位直接对标 OpenAI Codex 与 Anthropic Claude Code，主打编程和办公场景。

**深度解读 & 洞察：**
- DeepSeek Harness 的最大差异是「开放架构 vs 闭源单体」。Codex 像 iPhone，性能高但生态封闭；DSH 像 Android，以 Cordis 为底板，任何人可以写插件并开源共享。
- 这种设计指向一个更激进的目标：**AI 自进化**。模型可以在不中断任务的情况下自己编写并安装插件，社区高质量插件再融回主线，形成模型与生态共同进化的飞轮。
- 对普通用户来说，DSH 目前仍是极客工具：缺少 Codex 的三栏布局、内置浏览器、文件管理等功能，UI 还在早期打磨阶段。

**影响：**
- 对 AI 编程工具市场偏利多：开源 Agent 运行时降低了企业自建 AI 编程工作流的门槛。
- 对 Cursor/Codex/Claude Code 偏空：如果 DSH 插件生态快速成熟，可能分流开发者社区注意力与企业采购预算。

### [Grok Bot 登场：登录账号替你干活的 AI 团队](https://mp.weixin.qq.com/s/VOMprzcbm93k6QqgoYJ5ZA)

马斯克旗下 SpaceXAI 推出 **Grok Bot**，定位为「AI 智能体团队」。每个 Bot 拥有专属云端计算机，可 24 小时运行，能登录用户账号、观察工作流并固化为可复用模板。多 Bot 之间可互相通信、分配任务，只在需要人类决策时暂停等待。

产品原型源自被 xAI 收购的 Cursor 母公司 Anysphere 内部代号「Sand」的项目，目前深度集成在 Cursor 基础设施中。订阅门槛较高：SuperGrok Heavy 300 美元/月，Cursor Ultra 200 美元/月，Cursor Teams Premium 120 美元/用户/月。

**深度解读 & 洞察：**
- Grok Bot 是马斯克把 xAI、SpaceX、Cursor 三方资源打通后的首个 Agent 产品形态。它不只是聊天机器人，而是可以直接操作现有软件界面、接管工作流的「云端数字员工」。
- 最大风险在于权限边界：Bot 能登录账号、操作网站、共享云端环境，一旦流程偏差可能在无人察觉的情况下造成连锁错误。目前只支持 Grok 模型，也缺乏跨模型灵活性。
- 它代表了 AI 从「回答问题」到「替我执行」的跃迁，但高昂订阅价和强自主权让它更像是面向极客和企业高阶用户的实验性产品。

### [Cursor 提前推出 Origin 自动化代码审查平台](https://news.aibase.com/zh/news/30303)

Cursor 准备提前向全量用户开放 **Origin**（内部代号 Cursor Review），这是一个自动化代码审查平台，由 Cursor 去年底收购的 Graphite 团队开发。

Origin 在 Cursor 网页端增加两个核心模块：**Codebase** 负责同步管理 GitHub 代码库，**Review** 负责自动化处理 Pull Request。日常未解决的 PR 由系统和 AI 协同处理，只在需要人类做关键决策时才发通知。

**深度解读 & 洞察：**
- AI 编程的瓶颈正在从「代码生成」转向「代码审查与合并」。当单个代码库每秒能完成 22.6 次提交时，传统人工 review 完全跟不上。
- Origin 的落地意味着 Cursor 要从代码编辑器扩展到完整的软件开发工具链，覆盖「生成 + 审查 + 合并」。
- 这也和 SpaceXAI 的整合有关：SpaceX 预计本季度完成对 Cursor 母公司 Anysphere 的 600 亿美元收购，未来 Origin 会直接接入 Agent 生态。

### [Zed 发布 Delta，打造 AI Agent 编程的多人协作环境](https://www.oschina.net/news/501922)

代码编辑器 Zed 团队发布 **Delta**，一个面向 AI Agent 编程的多人协作环境。Delta 建立在实时同步数据库 DeltaDB 之上，允许开发者在代码任意一行直接添加评论，评论会随代码演化持续锚定。云端 Cloud Runner 支持 AI Agent 在开发者关闭电脑后继续运行。

**深度解读 & 洞察：**
- Delta 的野心是把代码审查从「提交后」前移到「编码过程中」，让对话成为代码演进的一部分。这与 Cursor Origin 的方向一致：AI 编程的下一个战场是协作流而非单点生成。
- Zed 用 Rust + WebAssembly + WebGL 实现桌面与浏览器一致体验，技术选型偏硬核，实际生态迁移成本仍需观察。

## 终端与入口：AI 从云端走向设备与场景

### [荣耀发布首款 Robot Phone：手机装上钛合金云台与系统级 Agent](https://www.qbitai.com/2026/08/471701.html)

荣耀在 8 月 12 日发布 **荣耀 Robot Phone**，首次把「机器人级」机械结构与系统级 Agent 架构同时塞进消费级手机。核心配置：
- 四自由度钛合金灵巧云台，加工精度 ±0.005 mm，云台电机仅 2.6 g；
- 搭载 **Agentic OS** 与 **YOYO Pro** 模式，与阿里千问大模型合作优化端侧方案；
- 与 ARRI 共研电影工业影像能力，支持 ARRI LogC3、ARRI Look、2.39:1 画幅；
- 第五代骁龙 8 至尊版、7060 mAh 青海湖电池、6.31 英寸高亮屏；
- 售价 9999 元起，8 月 18 日开售。

**深度解读 & 洞察：**
- Robot Phone 是智能手机从「数字智能」迈向「具身智能」的激进实验。云台让手机第一次有可动的「身体」，Agent 负责指挥身体完成现实任务。
- 它的意义在于探索下一代交互范式：手势、表情、音乐律动、自动追焦、直播运镜等，都可以被 Agent 主动执行，而不只是被动响应语音指令。
- 但 9999 元起售价、机械结构长期可靠性、续航与进灰风险，决定了它短期内仍是面向极客和创作者的前沿设备。

### [谷歌 DeepMind 手语转文本模型 SL2T 首次进入消费级 Pixel 11](https://www.ithome.com/0/989/105.htm)

谷歌 DeepMind 发布 **SL2T** 大规模多语言手语转文本翻译模型，并直接内置到 **Pixel 11** 系列的 Gboard 和 Live Transcribe 中。这是手语 AI 首次进入普通消费手机。

模型用超过 50 种手语、约 10 万小时数据训练。用户对着前置摄像头做手语动作，即可编辑消息、检索网页或与 Gemini 对话。隐私设计上，只有动作坐标会传输，原始视频立即删除不上云。初期仅支持美国手语转英文，后续扩展更多手语和设备。

**深度解读 & 洞察：**
- 手语不是手势的简单对应，而是拥有独立语法和词汇的自然语言。SL2T 直接解析身体多部位同步运动，更接近真正的机器翻译而非逐词转换。
- 把模型放在端侧、不上传原始视频，是 AI 无障碍功能落地的关键：听力障碍群体对隐私更敏感，离线/端侧处理能消除使用顾虑。
- 这标志着 AI 无障碍交互从科研验证走向消费产品，科大讯飞、华为、苹果都在同方向布局。

**深度解读 & 洞察：**

### [小米发布澎湃 OS 4 与超级小爱 2.0「专家模式」积分订阅](https://www.ithome.com/0/989/242.htm)

小米发布澎湃 OS 4，带来 **超级小爱 2.0**，并推出「专家模式」积分会员订阅方案。快速模式（日常问答、智能家居、修图等）免费；专家模式处理复杂任务或生成内容时消耗积分，所有用户每月免费送 1000 积分。

**深度解读 & 洞察：**

### [2026 最大规模 AI 供应链泄露：LiteLLM 投毒波及 2500 家企业、195TB 数据](https://www.ithome.com/0/989/142.htm)

科技媒体 Ars Technica 报道称，今年 3 月爆发的 **LiteLLM 投毒事件**被安全公司 CloudSEK 与 Hudson Rock 披露细节：在约 40 分钟攻击窗口内，约 **2500 家企业**受影响，约 **195TB** 密码数据泄露，被称为 2026 年最大规模 AI 供应链泄露。

LiteLLM 是一个开源 AI API 网关，支持以统一格式调用 OpenAI、Anthropic、Azure 等 100 多家服务商的 API。暴露信息包括云密钥、代码仓库 Token、SSH 密钥、Kubernetes 密钥、软件包发布凭据、环境变量及 AI 服务商密钥等。受影响企业包括英伟达、AWS、三星、Salesforce、思科、西门子、标普全球、空客美国航天与防务、伦敦证券交易所集团、联邦快递、联发科、大众、德勤、X 公司等。

**深度解读 & 洞察：**
- AI 供应链正在成为新的单点故障源。一个被广泛应用的开源网关被投毒，就能在几十分钟内撬开全球顶尖企业的密钥仓库。
- 问题核心在于「统一入口 = 统一风险」。企业为了简化多模型调用而集中管理 API，但一旦这个入口失守，损失会被放大数倍。
- 这也给开源商业化敲响警钟：关键基础设施组件需要更严格的代码审计、签名验证和供应链安全治理，而不是单纯追求功能集成。

### [Claude 与人类数学家攻克 30 年悬而未决的 668 阶哈达玛矩阵](https://www.qbitai.com/2026/08/472059.html)

Anthropic 研究员、数学家 Levent Alpöge 与两位人类合作者借助 Claude 成功构造出 **668 阶哈达玛矩阵**，并一次性扫清 2000 阶以下全部 12 个未知阶数。相关成果以一段含 23828 个符号的推文形式发布，经独立数据库 VibeMathed 复现验证。

哈达玛矩阵要求方阵中只填 +1 和 -1，且任意两行对应元素相乘后求和为 0。668 阶自 2005 年人类构造出 428 阶后一直是未解问题，被收录在 FrontierMath 基准测试中。

**深度解读 & 洞察：**
- 这是 AI 辅助数学研究的标志性事件。FrontierMath 50 个开放问题中已有 4 个被 AI 攻克，其中 2 个由 GPT 解决，2 个由 Claude 解决。
- AI 在这里不是全自动解题，而是作为「协同推理伙伴」，帮助人类数学家发现搜索策略和构造方法。这种「人机深度绑定」正在重构前沿数学研究节奏。
- 不过，该方法是否可推广到 2000 阶以上，仍需完整技术报告验证。
